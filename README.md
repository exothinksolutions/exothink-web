# Exothink · Sitio web

Sitio estático (HTML, CSS y JS) construido a partir del Manual de Identidad Corporativa de Exothink.

- `index.html`, `soluciones.html`, `nosotros.html`, `contacto.html`
- `assets/css/style.css` · `assets/js/main.js` · `assets/img/`

No requiere build. En Vercel: importar el repositorio con el preset **Other** y sin comando de build.
El formulario de contacto no usa servidor: abre el correo (info@exothink.biz) o WhatsApp con el mensaje armado.
